# 语体基准：49 篇开放获取 Nature 论文的实测分位

## 语料怎么来的

- 来源：Europe PMC，检索式 `JOURNAL:"Nature" AND OPEN_ACCESS:y`，2018–2025 每年按引用数取前 14 篇。
- 解析：JATS 全文 XML，取摘要与正文段落；参考文献、图注、表格不计入。
- 去重与失败剔除后，**49 篇**进入统计。每篇正文 6,282–10,443 词（P25–P75）。
- 统计口径：每篇先算一个值，再取跨篇的 P25 / P50 / P75。不是把所有句子混在一起算。

复算：

```bash
python scripts/build_corpus.py --per-year 14 --from-year 2018 --to-year 2025
```

脚本只保存聚合分位数，不保存、不再分发论文全文。

## 三个值得注意的读数

**1. 句末引文 84%。**
顶刊不是「句子中间插引文」，而是让被支撑的主张走到句末，引文紧随其后。句首引文通常只用于承接前文，不用于支撑本句。

**2. 无支撑强断言几乎为零。**
`demonstrate`、`prove`、`establish`、`clearly` 这类词，加上「没有引文、没有数据」的组合，在 49 篇里 P75 只有 0.24 次/千词。审稿人对这个组合极其敏感。

**3. 摘要只有 222 词。**
AI 起草的摘要常在 280–320 词，前一半是背景。顶刊摘要把背景压到一句，把数字和结论提前。

## 局限

- 只覆盖 Nature，不含 Science、Cell、Nature 子刊。不同刊的语体有差异，跨刊使用要重算。
- 只覆盖开放获取全文；能拿到 XML 的样本偏向近年、偏生命科学与物质科学。
- 按引用数取样，语体上偏向高影响力论文，不代表全部刊文。
- 短文本（<1500 词）的密度指标波动很大。检查器会提示，不要为对齐分位数硬改。
- 所有数字是 2026-10 的观测，模型与编辑规范都在变。

## 中文 T1 基准

`paper_voice/data/cn-t1.json` 来自 30 篇中文 T1 期刊论文（《文学评论》14 篇 + 《中国现代文学研究丛刊》16 篇）的实测：

| 指标 | P25 | P50 | P75 |
|---|---|---|---|
| 平均句长（字） | 46.9 | 54.8 | 62.0 |
| 句长 CV | 0.54 | 0.60 | 0.65 |
| 段均字数 | 210 | 262 | 314 |
| 段末引文收束 | 10.5% | 19.0% | 27.5% |

口径注意：中文的「段末引文收束」指段落最后一个元素是引文，不是句末引文；与英文的 `citation_end_ratio` 不是同一个东西。中文语料已归档，分位数保留。
