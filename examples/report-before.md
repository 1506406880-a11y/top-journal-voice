## 修改顺序

1. **先补证据，再改句子。** 标出所有强断言，逐条问：这句话的支撑在哪一句、哪一个图、哪一条引文。
2. **把引文移到被支撑句的末尾。** 句首引文只用于承接，不用于支撑本句。
3. **按节型调语气。** Introduction 允许对冲，Discussion 要克制，Results 只写看到了什么。
4. **最后才动句子长度和连接词。** 先改信息顺序，再考虑拆句。

## P0 · 主张与证据

### 无支撑强断言：2.97（顶刊带 0–0.240 次/千词）

- 为什么：强断言（demonstrate / prove / establish / clearly）+ 无引文 + 无数据，是审稿意见里最常见的靶子。
- 怎么改：补证据，或把断言降级：demonstrate→show，prove→these results suggest，clearly→（删）。

### 句末引文占比：33%（顶刊带 78–89%）

- 为什么：引文落在被支撑句的末尾，主张与证据同句；句首堆引文会切断这层关系。
- 怎么改：把支撑引文移到被支撑句的句末；句首引文只用于承接前文，不用于支撑本句。

## 其余越界项

- **学术套词密度**（13.4，带 0.120–0.750 次/千词）：换成具体动作或对象：underscore→show，pivotal→（说清它决定了什么），robust→（说清对哪种扰动稳健）。
- **强断言密度**（5.94，带 0.300–0.810 次/千词）：把 demonstrate / prove / establish 降级为 show / find / suggest；只有多组独立证据收敛时才用强断言。
- **引文密度**（5.94，带 16.4–24.8 次/千词）：引文密度偏低时，检查每个强主张是否有来源；Nature 正文约 16–25 次/千词。
- **摘要词数**（279，带 187–238 词）：按四步压缩：一句缺口，一句做法，两三句结果，一句意义。删背景教科书式铺垫。
- **对冲词密度**（4.46，带 1.83–4.31 次/千词）：每一处限定都要有具体所指：样本、范围、模型假设。删掉空转的 possibly / potentially。
- **摘要平均句长**（69.8，带 22.8–28 词）：把摘要长句拆成主谓宾；一句只放一个结果。
- **连接词密度**（11.9，带 1.73–3.20 次/千词）：删掉句首连接词，让语序承担转折；真正需要显式路标时保留一处。
- **名词化密度**（58.0，带 37.6–43.4 次/千词）：动词化：implementation→implement，assessment→assess，utilization→use。
- **平均句长**（30.6，带 22.8–25.1 词）：把插入语、条件从句独立成句；先让主谓出现。
- **题名词数**（14，带 8–11 词）：压到 15 词内：对象 + 动作 + 结果，删掉壳和形容词。
